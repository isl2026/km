Configuración de Auditoría

Parámetros para clasificar diferencias de kilometraje

Diferencia hasta este valor → amarillo
Diferencia mayor a este valor → rojo
Traslados menores se auditan como mínimo
¿Cómo funciona la auditoría con BASE? Cuando un traslado tiene BASE distante, la app calcula:

📍 KM Base → Origen del paciente
📍 KM Origen → Destino del paciente
📊 KM Total Google = Base + Traslado

Este total se compara con el KM declarado por el prestador. Si hay diferencia mayor a la tolerancia configurada, se marca la alerta correspondiente.

Regla de mínimo: Si el KM traslado (sin base) es menor a 10 km, se aplica el mínimo.

Regla NEGATIVO: Cuando el móvil llegó a origen pero el paciente canceló el viaje. Se factura como mínimo y siempre se clasifica como ✓ Conforme — es un caso válido, no una diferencia a auditar. En la planilla debe figurar la palabra NEGATIVO en la columna KM.
